## Описание

Адаптивная страница музыкального сервиса AMP. В интерфейсе представлены обложка и сведения о композиции, панель управления, визуальный прогресс воспроизведения, подборка следующих и популярных треков.

В проекте демонстрируются CSS3-эффекты: `:hover`, `:focus-visible`, `::before` и `::after`, `transition`, `transform`, `linear-gradient`, `box-shadow`, `@keyframes`, CSS-переменные и медиазапросы. Анимации служат только визуальной индикацией и не изменяют логику воспроизведения.

## Запуск

Откройте `index.html` в браузере. Внешний CSS и изображения подключаются относительно корня проекта.
