# Лабораторная работа № 6 — Музыкальный плеер

Учебный проект по созданию веб-страницы музыкального плеера в тёмной неоновой стилистике. Реальное воспроизведение аудио не подключено — реализована визуальная интерактивность.

**Выполнил:** Смирнов Никита Русланович  
**Группа:** ИСТ-33  
**Вариант:** 3

## Запуск
Распакуйте архив, откройте папку `lab-6` и запустите `index.html` в современном браузере. Дополнительная установка программ и библиотек не требуется.

## Структура
- `index.html` — разметка главной страницы плеера.
- `css/style.css` — оформление, анимации и адаптивные правила.
- `images/` — обложки альбома и превью композиций.

## Использованные технологии
- **HTML5:** семантическая разметка, панель управления плеером, список композиций.
- **CSS3:** переменные, `linear-gradient`, `box-shadow`, `transition`, `transform`, псевдоэлементы `::before`/`::after`, состояния `:hover`/`:focus`.
- **Анимации:** `@keyframes` для визуализатора звуковых волн.
- **JavaScript:** переключение состояния кнопки воспроизведения, избранного и выбор композиции.
- **Адаптивность:** медиазапросы для экранов 1024 px, 768 px, 480 px и 360 px.

## Контрольные размеры
Для проверки адаптивности используйте ширину **1440 px**, **768 px**, **375 px** и дополнительно **320 px**. В проекте предусмотрены стили для компьютера, планшета и смартфона.

## Публикация
Загрузите содержимое папки `lab-6` в репозиторий GitHub. В настройках репозитория откройте раздел **Pages** и выберите ветку для публикации.
