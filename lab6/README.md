Тема работы
Создание веб-страницы музыкального плеера с использованием HTML и CSS.
Описание проекта
Проект представляет собой адаптивный макет музыкального плеера в тёмной неоновой стилистике. На странице размещены:
- обложка музыкального альбома;
- название композиции и имя исполнителя;
- панель управления плеером;
- индикатор прогресса композиции;
- визуализатор звуковых волн;
- список доступных композиций.
Интерфейс демонстрирует внешний вид музыкального плеера. Переключение визуального состояния кнопки воспроизведения, избранного и выбор композиции реализованы на JavaScript. Реальное воспроизведение аудиофайлов не подключено.
Структура проекта

├── README.md           # Описание проекта

    └── album-cover.png # Обложка альбома
Использованные технологии
- HTML5 — структура веб-страницы и семантические элементы.
- CSS3 — оформление интерфейса и адаптивная вёрстка.
- JavaScript — обработка нажатий и переключение выбранной композиции.
В оформлении применены требуемые CSS-возможности:
- @keyframes — анимация визуализатора;
- transition — плавное изменение состояния элементов;
- transform — визуальные преобразования;
- linear-gradient — градиентные фоны;
- box-shadow — тени и неоновое свечение;
- ::before и ::after — декоративные псевдоэлементы;
- :hover и :focus — интерактивные состояния элементов.
Запуск проекта
1. Распаковать архив проекта.
2. Открыть папку lab-6.
3. Запустить файл index.html в современном браузере.
