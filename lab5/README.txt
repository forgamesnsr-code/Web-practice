# Практическая работа №5. Семантические элементы HTML5

**ФИО:** Смирнов Никита Русланович
**Группа:** ИСТ-33
**Вариант:** 3 — Интернет-магазин

## Краткое описание
Веб-страница интернет-магазина TechnoMarket, разработанная с использованием
семантических элементов HTML5 (`header`, `nav`, `main`, `section`, `article`,
`aside`, `footer`) и оформленная с помощью CSS3.

## Реализованные элементы и приёмы
- **Семантика:** `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `address`
- **CSS3:** Box Model, Grid Layout (каталог и общий макет), Flexbox (шапка, карточки),
  `:hover`, `:focus-visible`, `::after`, `transition`, `transform: translateY() / scale()`,
  `box-shadow`, `border-radius`, `linear-gradient`, `radial-gradient`, `position: sticky`
- **Адаптивность:** media queries на 1024px и 768px, без горизонтального переполнения
- **Доступность:** `alt` у изображений, `aria-label`, `label` для поиска, `:focus-visible`
