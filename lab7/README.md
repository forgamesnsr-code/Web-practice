Описание проекта
Учебный проект для практической работы №7. Сайт представляет собой адаптивный одностраничный лендинг для фитнес-приложения FitWay.

В проекте реализованы:
- Ручное переключение Desktop/Mobile (с помощью скрытого чекбокса и селектора :checked на чистом CSS).
- Автоматическое переключение при изменении ширины окна браузера (через @media запросы).
- Семантическая верстка HTML5.
- Стилизация с использованием CSS-переменных, clamp(), Flexbox и CSS Grid.
- Мобильное меню (бургер) на чистом CSS без использования JavaScript.

Технологии:
- HTML5
- CSS3 (Flexbox, Grid, CSS Variables, Media Queries)
- Google Fonts (Manrope)

Структура проекта:
- index.html — основная разметка страницы.
- css/style.css — файл со стилями и медиазапросами.
- images/ — папка с графическими иллюстрациями.
- README.md — описание проекта.
