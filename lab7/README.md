## Описание проекта

FitWay — адаптивная страница персонального фитнес-приложения. На странице размещены профиль пользователя, статистика, текущая тренировка, расписание и рекомендации.

Вёрстка выполнена на HTML и CSS. Основная Dashboard-композиция построена на CSS Grid с использованием Grid Areas. Для внутренних блоков, карточек показателей, навигации и расписания применяется Flexbox. Для адаптации используется контрольная ширина 768 px.

В шапке расположено ручное переключение Auto / Desktop / Mobile. В режиме Auto представление автоматически меняется при изменении ширины окна. Состояние кнопки текущей тренировки сохраняется при перестройке страницы.

## Запуск

Откройте `index.html` в браузере. Для корректной работы всех локальных изображений сохраняйте папки `css`, `js` и `images` рядом с HTML-файлом.
