# FitWay — адаптивная главная страница

Учебный проект для практической работы №7, вариант 3. Сайт представляет фитнес-приложение FitWay: тренировки, планы питания, отслеживание прогресса и мобильное приложение.

## Запуск
Откройте `index.html` в браузере. Для корректной загрузки шрифтов требуется подключение к интернету; локальные иллюстрации находятся в каталоге `images`.

## Структура
- `index.html` — разметка главной страницы.
- `css/style.css` — оформление, сетки и адаптивные правила.
- `images/` — SVG-иллюстрации.

## Использованные технологии
- HTML5: семантические секции, навигация, форма и метатеги.
- CSS3: переменные, `clamp()`, переходы, тени, скругления и псевдоклассы.
- Flexbox: шапка, статистика, кнопки, рекламный блок и подвал.
- CSS Grid: главный экран и сетки карточек.
- Media queries: адаптация для экранов 1024 px, 768 px, 480 px и 360 px.
- CSS-only: мобильное меню раскрывается с помощью checkbox и селектора `:checked`; JavaScript не используется.

## Контрольные размеры
Для проверки адаптивности используйте ширину 1440 px, 768 px, 375 px и дополнительно 320 px. В проекте предусмотрены стили для компьютера, планшета и смартфона.
