# FitWay — адаптивный персональный фитнес-дашборд

Учебный проект для лабораторной работы №7, вариант 3. Сайт представляет персональный кабинет фитнес-приложения FitWay. На главной странице отображаются профиль пользователя, статистика тренировок, текущая тренировка, расписание занятий и персональные рекомендации.

## Запуск
Откройте `index.html` в браузере. Для корректной работы переключения режимов Desktop/Mobile и кнопки начала тренировки необходимо подключение файла `js/app.js`. Внешние ресурсы, если используются, требуют подключения к интернету.

## Структура
- `index.html` — HTML-разметка фитнес-дашборда.
- `css/style.css` — оформление, сетки и адаптивные правила.
- `js/app.js` — переключение режимов отображения и обработка кнопки тренировки.
- `images/` — локальные фотографии тренировок, бега, растяжки, воды, питания и спортивного инвентаря. Все изображения входят в архив и не требуют подключения к интернету.

## Использованные технологии
- HTML5: семантическая разметка, секции профиля, статистики, тренировок и расписания.
- CSS3: переменные, скругления, тени, переходы и оформление элементов интерфейса.
- CSS Grid: расположение основных блоков дашборда с использованием `grid-template-areas`.
- Flexbox: выравнивание элементов внутри карточек, шапки, профиля и расписания.
- Media queries: адаптация интерфейса для мобильных устройств с контрольной шириной 768 px и дополнительными правилами для узких экранов.
- JavaScript: ручное переключение режимов Desktop, Mobile и Auto, автоматическое изменение отображения при изменении размера окна браузера.

## Контрольные размеры
Для проверки адаптивности используйте ширину 1440 px, 768 px, 375 px и дополнительно 320 px. В проекте предусмотрены режимы отображения для компьютера и смартфона, а также автоматическая адаптация при изменении ширины окна браузера.
